# Real Estate Web Application

A full-stack real estate web application built with the **MERN stack**, allowing users to browse, create, and manage property listings.

## Features

* User registration and login
* Google authentication
* Create, update and delete property listings
* Property image uploads
* Browse and filter properties
* Rent and sale property types
* User-specific listing management
* Admin dashboard for managing platform activity

## Tech Stack

* React
* Node.js
* Express.js
* MongoDB
* Redux Toolkit
* Firebase Authentication

## Getting Started

```bash
npm install
npm run dev
```

Configure the required environment variables before running the application.

## Purpose

Built as a full-stack real estate project to demonstrate authentication, REST APIs, database management, state management, CRUD operations, and user/admin functionality.
